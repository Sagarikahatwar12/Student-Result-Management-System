# Student Result System

A console-based Java program that takes a student's marks and calculates the total, percentage, and Pass/Fail result.

## Features
- Takes student name, roll number, and marks of 3 subjects (Java, DBMS, Maths)
- Calculates total marks and percentage
- Shows PASS (40% or above) or FAIL

## Technology
Java

## How to Run
    javac StudentResult.java
    java StudentResult
